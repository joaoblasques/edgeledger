# Learning

One ordered sequence, ~2 hrs/week (revised 2026-09-12, down from ~6 hrs/week across two
parallel tracks — at two hours a week, two threads get an hour each and lose continuity
between weekly sessions; see `../horizon-change-2026-09-12.md`). The A/B split below is kept
as a *taxonomy* for tagging notes, not as two separate clocks.

Notes are written in the style of
[A0](track-a/a0-what-a-probability-is.md): built from first principles in plain language, one
idea at a time, with the technical term introduced only once the idea it names is already
understood. Original two-track framing: Moved here from the vault on 2026-08-03 so
learning material is canonical in the repo (matches how the rest of this project's docs work)
and doubles as source content for the public site.

- [Track A — Probability & Inference](track-a/README.md) — *"Is my edge real, and how much do I
  bet?"*
- [Track B — Modelling Foundations](track-b/README.md) — *"Where does a probability actually
  come from?"*

Concept notes are added as they're learned, not pre-created — each track's `README.md` is the
index and gets a link added per note.
